Taller Práctico PLEM: Modelado y Casos Gerenciales

Restricciones "Uno u otro" (Either-Or)

Problema: Procesar obligatoriamente en Máquina A o B. Máq A: \(2x_1 + x_2 \le 100\). Máq B: \(x_1 + 3x_2 \le 90\). Maximizar \(Z = 10x_1 + 15x_2\).

Formulación Matemática
  • \(\max Z = 10x_1 + 15x_2\)
  • S.A: \(2x_1 + x_2 \le 100 + M(1-y)\)
  • \(x_1 + 3x_2 \le 90 + My\)
  • \(x_1, x_2 \ge 0; \quad y \in \{0, 1\}\)
Código Python (PuLP)
import pulp
prob = pulp.LpProblem("Either_Or", pulp.LpMaximize)
x1 = pulp.LpVariable('x1', lowBound=0)
x2 = pulp.LpVariable('x2', lowBound=0)
y = pulp.LpVariable('y', cat='Binary')
M = 10000

prob += 10 * x1 + 15 * x2
prob += 2 * x1 + x2 <= 100 + M * (1 - y)
prob += x1 + 3 * x2 <= 90 + M * y

prob.solve()
print(f"x1: {pulp.value(x1)}, x2: {pulp.value(x2)}, y: {pulp.value(y)}, Z: {pulp.value(prob.objective)}")

Nivel 1: Presupuesto de Capital

Escenario 1: Presupuesto \$100M. 4 proyectos: P1(\$40M, VPN \$50M), P2(\$50M, VPN \$65M), P3(\$30M, VPN \$40M), P4(\$20M, VPN \$30M). P2 solo si P1 se ejecuta (\(x_2 \le x_1\)).

1. ¿Cuál es el portafolio óptimo?



Formulación:
\(\max 50x_1 + 65x_2 + 40x_3 + 30x_4\)
\(40x_1 + 50x_2 + 30x_3 + 20x_4 \le 100\)
\(x_2 \le x_1\), \(x_i \in \{0,1\}\)
Código Python: 
import pulp
p = pulp.LpProblem("Cap_Budget", pulp.LpMaximize)
x = pulp.LpVariable.dicts("x", range(1,5), cat='Binary')
p += 50*x[1] + 65*x[2] + 40*x[3] + 30*x[4]
p += 40*x[1] + 50*x[2] + 30*x[3] + 20*x[4] <= 100
p += x[2] <= x[1]
p.solve()
# Óptimo: P1, P3, P4 (VPN = 120M)
Escenario 2 (Knapsack Entero): Buque 15 ton. 3 contenedores (máx 2 c/u). Tipo X (4t, \$10k), Y (5t, \$13k), Z (7t, \$15k).

2. ¿Cuál es la carga óptima?



Formulación:
\(\max 10x + 13y + 15z\)
\(4x + 5y + 7z \le 15\)
\(0 \le x,y,z \le 2\), enteros.
Código Python: 
import pulp
p = pulp.LpProblem("Knapsack", pulp.LpMaximize)
x = pulp.LpVariable('x', lowBound=0, upBound=2, cat='Integer')
y = pulp.LpVariable('y', lowBound=0, upBound=2, cat='Integer')
z = pulp.LpVariable('z', lowBound=0, upBound=2, cat='Integer')
p += 10*x + 13*y + 15*z
p += 4*x + 5*y + 7*z <= 15
p.solve()
# Óptimo: x=1, y=2, z=0 (Ganancia = 36k)
