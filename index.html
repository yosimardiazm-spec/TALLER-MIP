Restricciones "Uno u otro" (Either-Or)

Problema: Procesar obligatoriamente en Máquina A o B. Máq A: \(2x_1 + x_2 \le 100\). Máq B: \(x_1 + 3x_2 \le 90\). Maximizar \(Z = 10x_1 + 15x_2\).

Formulación Matemática
  • \(\max Z = 10x_1 + 15x_2\)
  • S.A: \(2x_1 + x_2 \le 100 + M(1-y)\)
  • \(x_1 + 3x_2 \le 90 + My\)
  • \(x_1, x_2 \ge 0; \quad y \in \{0, 1\}\)
Código Python (PuLP)
import pulp
prob = pulp.LpProblem("Either_Or", pulp.LpMaximize)
x1 = pulp.LpVariable('x1', lowBound=0)
x2 = pulp.LpVariable('x2', lowBound=0)
y = pulp.LpVariable('y', cat='Binary')
M = 10000

prob += 10 * x1 + 15 * x2
prob += 2 * x1 + x2 <= 100 + M * (1 - y)
prob += x1 + 3 * x2 <= 90 + M * y

prob.solve()
print(f"x1: {pulp.value(x1)}, x2: {pulp.value(x2)}, y: {pulp.value(y)}, Z: {pulp.value(prob.objective)}")

Nivel 4: Ruteo y Scheduling

Escenario 7 (Subtours TSP): Matriz relajada arroja \(x_{AB}=1, x_{BA}=1\) y \(x_{CD}=1, x_{DC}=1\).

7. ¿Qué anomalía física demuestra este resultado?



Formulación MTZ (Lógica):
Para evitar subtours, se agrega la variable continua \(u_i\) (posición de visita).
\(u_i - u_j + n x_{ij} \le n - 1 \quad \forall i,j \ge 2, i \neq j\)
Código Python (Estructura MTZ): 
import pulp
# Asumiendo n nodos y costos C[i][j]
p = pulp.LpProblem("TSP_MTZ", pulp.LpMinimize)
n = 4
x = pulp.LpVariable.dicts("x", (range(n), range(n)), cat='Binary')
u = pulp.LpVariable.dicts("u", range(n), lowBound=0, upBound=n-1)

for i in range(1, n):
    for j in range(1, n):
        if i != j:
            p += u[i] - u[j] + n * x[i][j] <= n - 1
# Esta restricción fuerza a que exista una secuencia única conectada
Escenario 8 (Job Shop): J1 (3h, Deadline en 4h). J2 (4h). Misma máquina sin solape.

8. ¿Cuál es la programación factible y el Makespan?



Formulación Disyuntiva:
\(t_1 + 3 \le t_2 + M(1-y)\)
\(t_2 + 4 \le t_1 + My\)
\(t_1 + 3 \le 4\) (Deadline J1)
\(\max Makespan \ge t_i + P_i\)
Código Python: 
import pulp
p = pulp.LpProblem("Job_Shop", pulp.LpMinimize)
t1 = pulp.LpVariable('t1', lowBound=0)
t2 = pulp.LpVariable('t2', lowBound=0)

y = pulp.LpVariable('y', cat='Binary')
M = 100

p += ms
p += t1 + 3 <= t2 + M*(1-y)
p += t2 + 4 <= t1 + M*y
p += t1 + 3 <= 4  # Deadline J1
p += ms >= t1 + 3
p += ms >= t2 + 4
p.solve()
# Óptimo: t1=0, t2=3, Makespan=7

Nivel 10: Supply Chain End-to-End

19. ¿Qué dinámica modela el solver binario?



Formulación Balance:
\(\sum X_{flex} + X_{dedicada} \ge Demanda Pico\)
Si \(\max(\sum X_{flex}) < Demanda\), entonces \(y_{dedicada} = 1\) obligatoriamente.
Código Python:

p += 1000*y_ded + 200*y_flex + 1*x_ded + 1.2*x_flex
p += x_ded + x_flex >= 500 # Peak
p += x_flex <= 400*y_flex # Capacity shortfall
p += x_ded <= 600*y_ded
p.solve()
# Óptimo: y_ded=1, x_ded=500. Flexibles insuficientes por sí solas.
