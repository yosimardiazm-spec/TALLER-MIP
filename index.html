Restricciones "Uno u otro" (Either-Or) con Penalización Big M

Problema: Una empresa fabrica dos productos (\(x_1\) y \(x_2\)). Debe procesarlos obligatoriamente en la Máquina A o en la Máquina B, pero no en ambas por temas de incompatibilidad. La Máquina A tiene una restricción de tiempo de \(2x_1 + x_2 \le 100\), y la B de \(x_1 + 3x_2 \le 90\). Maximizar beneficio \(Z = 10x_1 + 15x_2\).

Formulación Matemática

Sea \(y \in \{0, 1\}\) donde \(y=1\) activa la Máquina A, y \(y=0\) la Máquina B. Usamos un número muy grande \(M\).

  • F.O: \(\max Z = 10x_1 + 15x_2\)
  • Sujeto a:
  • \(2x_1 + x_2 \le 100 + M(1-y)\)
  • \(x_1 + 3x_2 \le 90 + My\)
  • \(x_1, x_2 \ge 0; \quad y \in \{0, 1\}\)
Código Python (PuLP)
import pulp

prob = pulp.LpProblem("Either_Or_Problem", pulp.LpMaximize)
x1 = pulp.LpVariable('x1', lowBound=0, cat='Continuous')
x2 = pulp.LpVariable('x2', lowBound=0, cat='Continuous')
y = pulp.LpVariable('y', cat='Binary')

M = 10000
prob += 10 * x1 + 15 * x2, "Beneficio"
prob += 2 * x1 + x2 <= 100 + M * (1 - y), "Maq_A"
prob += x1 + 3 * x2 <= 90 + M * y, "Maq_B"

prob.solve()
print("x1 =", pulp.value(x1), "| x2 =", pulp.value(x2), "| Beneficio =", pulp.value(prob.objective))
